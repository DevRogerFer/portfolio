Projetos

To-Do Manager - Gerencie suas tarefas com eficiência.

Aplicação fullstack de gerenciamento de tarefas desenvolvida com React, Vite e Tailwind CSS. Permite criar, visualizar, editar e excluir tarefas com diferentes status — not started, in progress e done —, além de exibir um dashboard com resumo geral das atividades. A API REST, construída com JSON Server, oferece CRUD completo com filtragem por status e período do dia, hospedada de forma serverless na Vercel.

Consulta de Documentos - Transforme documentos em conhecimento.

Solução de IA que transforma documentos PDF em uma base de conhecimento pesquisável por linguagem natural. O usuário faz upload dos arquivos e pode realizar perguntas como se estivesse conversando com os documentos, recebendo respostas rápidas, precisas e contextualizadas. Ideal para empresas e profissionais que desejam localizar informações com agilidade, reduzindo tempo de busca e aumentando a produtividade.

Lista de Tarefas - Mantenha-se organizado(a) diariamente.

Aplicativo simples e eficiente para organizar tarefas do dia a dia. Permite adicionar, concluir e remover atividades com facilidade, salvando tudo automaticamente no navegador. Com design limpo e responsivo, funciona em qualquer dispositivo. Ideal para quem busca produtividade e organização sem complicação.

Gerador de Dietas - Sua dieta ideal, gerada com inteligência

Plataforma inteligente que cria planos alimentares personalizados a partir dos dados do usuário. Com interface intuitiva e resposta em tempo real, o sistema combina um backend robusto com IA e um frontend moderno para oferecer recomendações práticas, rápidas e adaptadas ao objetivo e rotina de cada pessoa.

Chatbot de Programação - Interativo Básico

Um chatbot interativo básico desenvolvido com React.js que responde perguntas sobre programação usando um sistema de correspondência de palavras-chave e um conjunto fixo de respostas pré-definidas. Desenvolvido como "Projeto 5 Estrelas" para o programa de treinamento The Accelerator da plataforma Workana.

DSList - API de Lista de Games

DSList e uma API back-end desenvolvida com Java e Spring Boot para organizar e reordenar listas de games. O projeto aplica padrao MVC, DTO, JPA/Hibernate e deploy em producao com Railway e PostgreSQL.

PrimeFlix - Catálogo de Filmes

PrimeFlix e uma aplicacao React para listar filmes em cartaz via API externa, visualizar detalhes, salvar favoritos no Local Storage e abrir trailers no YouTube, com navegacao por rotas usando React Router DOM.
