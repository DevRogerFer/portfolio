React Hooks: useMemo

React | Hooks | useMemo

⚛️ Dominando os React Hooks: useMemo

Quando uma aplicação React realiza cálculos custosos, cada nova renderização pode repetir operações desnecessárias. É nesse cenário que o useMemo pode ajudar a otimizar a performance.

🧠 O que é o useMemo?

O useMemo é um Hook que permite armazenar em memória o resultado de um cálculo entre renderizações. Se suas dependências não mudarem, o React reutiliza o valor já calculado em vez de executar a operação novamente.

⚙️ Como funciona?

O useMemo recebe uma função de cálculo e uma lista de dependências. Na primeira renderização, o cálculo é executado. Nas seguintes, o React compara as dependências e só refaz o cálculo quando algum valor utilizado por ele muda.

🔄 Um problema comum

Imagine um componente que possui um estado numérico e outro relacionado a um campo de texto. Se o componente executar uma função lenta diretamente durante a renderização, alterar apenas o texto também poderá fazer esse cálculo ser repetido.

Nesse exemplo, isso vai gerar chamadas desnecessárias de uma função lenta. Com o useMemo, o resultado passa a ser recalculado somente quando o número utilizado como dependência é alterado.

🚀 Quando usar?

O useMemo faz mais sentido quando existe um cálculo realmente custoso, quando um valor memoizado é passado para um componente otimizado com memo ou quando esse valor é utilizado como dependência de outro Hook.

⚠️ Use com critério

O useMemo é uma otimização de performance, não uma solução para corrigir lógica incorreta. Seu uso indiscriminado pode tornar o código menos legível e consumir recursos desnecessariamente.

Outro ponto importante: o useMemo não deixa a primeira renderização mais rápida. Seu benefício aparece ao evitar trabalho repetido em renderizações posteriores.

Hooks devem ser chamados no nível superior do componente ou de Hooks customizados, nunca dentro de condicionais ou loops.

📊 Performance deve ser medida

Antes de adicionar useMemo, vale identificar se o cálculo realmente representa um custo relevante. A documentação do React recomenda medir a performance e usar memoização quando houver um benefício perceptível.

📌 Conclusão

Dominar o useMemo é entender que memoização não significa “usar em tudo”. O objetivo é evitar cálculos desnecessários quando isso realmente traz benefício. Antes de aplicar o Hook, avalie o custo da operação e meça a performance da aplicação.
