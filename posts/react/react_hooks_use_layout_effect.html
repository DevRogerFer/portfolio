React Hooks: useLayoutEffect

React | Hooks | useLayoutEffect

⚛️ Dominando os React Hooks: useLayoutEffect

Quando uma interface precisa medir, posicionar ou ajustar elementos do DOM antes que o usuário veja a tela, o useLayoutEffect pode ser a escolha certa. Ele é uma variação do useEffect para efeitos que precisam acontecer antes da pintura do navegador.

🧠 O que é o useLayoutEffect?

O useLayoutEffect executa seu efeito depois que o React aplica alterações ao DOM, mas antes que o navegador apresente a atualização visual. Isso é útil quando o efeito depende das dimensões ou da posição de elementos.

Já o useEffect acontece posteriormente e, em situações visuais, pode permitir que uma versão intermediária seja exibida antes do ajuste. A documentação oficial do React recomenda preferir useEffect sempre que possível e reservar useLayoutEffect para casos que exigem trabalho antes da pintura.

🔍 useEffect x useLayoutEffect

A principal diferença está no momento da execução:

  • 🔹 useEffect: adequado para efeitos que não precisam bloquear a pintura.
  • 🔹 useLayoutEffect: indicado quando é necessário medir ou modificar o layout antes da atualização ser exibida.

Essa diferença pode evitar efeitos como um elemento aparecer em uma posição e “saltar” para o local correto logo depois.

📐 Um caso prático

Imagine um modal, tooltip ou menu que precisa ser posicionado com base na localização de outro elemento. A interface precisa existir no DOM para que sua posição possa ser medida e, então, ajustada.

Com useLayoutEffect, essa medição e correção podem acontecer antes da pintura. Assim, o usuário recebe diretamente a posição final, proporcionando uma experiência mais fluida. Esse é justamente o tipo de situação explorado nas páginas sobre posicionamento de modal.

⚠️ Use com cuidado

O useLayoutEffect não deve substituir o useEffect automaticamente. Como seu código bloqueia o navegador de exibir a tela enquanto é executado, seu uso excessivo pode prejudicar o desempenho.

Hooks também devem ser chamados no nível superior do componente ou de Hooks personalizados, nunca dentro de condições ou loops.

Effects são executados no cliente e não durante a renderização no servidor.

Em aplicações com renderização no servidor, esse comportamento precisa ser considerado.

🚀 Quando usar?

Pense no useLayoutEffect quando precisar:

  • 📏 medir dimensões de elementos;
  • 📍 calcular posições no DOM;
  • 🧩 ajustar elementos antes da exibição;
  • 💬 posicionar tooltips, menus ou modais;
  • ✨ evitar “piscadas” ou mudanças visuais perceptíveis.

Dominar esse Hook não significa usá-lo em todo lugar. Significa reconhecer quando o timing da atualização visual realmente importa. No React, performance e experiência do usuário caminham juntas.
