JavaScript | Strings | Métodos ES6

🚀 StartsWith vs EndsWith em JavaScript: quando usar cada um?

No universo do JavaScript, trabalhar com strings é essencial e métodos como .startsWith() e .endsWith() são extremamente úteis para validações rápidas e elegantes.

🔍 O que é o .startsWith()?

O método .startsWith() verifica se uma string começa com determinado valor, retornando true ou false.

Também é possível informar a posição inicial da busca.

Ideal para validar prefixos, como URLs, nomes ou padrões iniciais.

📍 O que é o .endsWith()?

Já o método .endsWith() verifica se uma string termina com determinado valor, também retornando true ou false.

Muito usado para validar extensões de arquivos ou sufixos.

⚖️ Semelhanças entre eles

  • ✅ ambos retornam valores booleanos (true ou false)
  • ✅ são case sensitive, sensíveis a maiúsculas e minúsculas
  • ✅ não aceitam expressões regulares, apenas strings
  • ✅ foram introduzidos no ES6 (ES2015)

⚔️ Principais diferenças

  • 🔸 .startsWith() verifica o início da string
  • 🔸 .endsWith() verifica o final da string
  • 🔸 .startsWith() aceita parâmetro de posição inicial
  • 🔸 .endsWith() aceita posição final, tamanho da string

💡 Quando usar cada um?

  • ✔ use .startsWith() para validar prefixos, como https em URLs
  • ✔ use .endsWith() para validar sufixos, como .jpg ou .pdf

🧠 Resumo prático

Se você quer saber como começa, use .startsWith().

Se quer validar como termina, use .endsWith().

Dominar esses métodos torna seu código mais legível, expressivo e evita soluções mais complexas com indexOf() ou regex.
